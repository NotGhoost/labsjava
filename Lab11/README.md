# Лабораторная работа 11 — вариант 18
Тема: игры, перегрузка и переопределение методов. `Main` показывает три версии `play`, собственные перегруженные методы наследников и вызовы `getDifficulty` через ссылки типа `Game`.

## Открытие в IntelliJ IDEA как Maven-проекта
1. Распакуйте архив. Выберите **File → Open** и откройте папку `Lab11` (или её файл `pom.xml`). Если IDEA спросит, как открыть файл, выберите **Open as Project**.
2. Подтвердите доверие к проекту и дождитесь импорта Maven и загрузки зависимостей. В **File → Project Structure → Project** выберите установленный JDK 8 или новее.
3. Откройте `src/main/java/Main.java` и нажмите зелёный треугольник возле метода `main` → **Run**. Альтернативно откройте окно Maven и запустите цель `compile`, затем `exec:java`.

Каждую лабораторную импортируйте отдельно: в проектах есть классы с одинаковыми именами. При первом импорте Maven нужен доступ к интернету для загрузки плагинов.

## Запуск через терминал
Из папки лабораторной, где находится `pom.xml`:
```
mvn compile exec:java
```
Либо сначала `mvn package`, затем `java -Dfile.encoding=UTF-8 -cp target/classes Main`. Нужны Maven и JDK 8 или новее. Исходные файлы имеют кодировку UTF-8, каждый класс находится в отдельном файле.
