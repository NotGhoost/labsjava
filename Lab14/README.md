# Лабораторная работа 14 — вариант 18
Выберите пункт 1–5 в меню; 0 завершает работу. Пункты 2 и 4 запрашивают соответственно 10 целых чисел и 15 вещественных значений скорости; числа можно вводить через пробелы или по одному в строке. Вещественные значения допускают точку или запятую.

Файлы создаются в `data/task1` ... `data/task5` относительно рабочей папки запуска. Каждое выполнение задания перезаписывает соответствующие файлы. Исходные файлы `f` разных заданий разделены, чтобы не затирать друг друга. В задании 1 в `Task1.java` приведён пример мечты, замените его на свой. В задании 3 создаются 20 случайных чисел от −100 до 100; в задании 5 используется заданный набор из 10 чисел. Отрицательные числа не считаются палиндромами; ноль считается кратным 8 и 11.

## Открытие в IntelliJ IDEA как Maven-проекта
1. Распакуйте архив. Выберите **File → Open** и откройте папку `Lab14` (или её файл `pom.xml`). Если IDEA спросит, как открыть файл, выберите **Open as Project**.
2. Подтвердите доверие к проекту и дождитесь импорта Maven и загрузки зависимостей. В **File → Project Structure → Project** выберите установленный JDK 8 или новее.
3. Откройте `src/main/java/Main.java` и нажмите зелёный треугольник возле метода `main` → **Run**. Альтернативно откройте окно Maven и запустите цель `compile`, затем `exec:java`.

Каждую лабораторную импортируйте отдельно: в проектах есть классы с одинаковыми именами. При первом импорте Maven нужен доступ к интернету для загрузки плагинов.

## Запуск через терминал
Из папки лабораторной, где находится `pom.xml`:
```
mvn compile exec:java
```
Либо сначала `mvn package`, затем `java -Dfile.encoding=UTF-8 -cp target/classes Main`. Нужны Maven и JDK 8 или новее. Исходные файлы имеют кодировку UTF-8, каждый класс находится в отдельном файле.
